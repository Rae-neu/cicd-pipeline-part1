\# CI/CD Pipeline (Part 1)



This project is a simple Go application used to demonstrate a basic CI/CD pipeline with GitHub Actions.



\## Project Contents



\- `calculator.go` - contains simple calculator functions

\- `calculator\_test.go` - contains unit tests

\- `go.mod` - Go dependency/module configuration

\- `.github/workflows/ci.yml` - GitHub Actions workflow
